# 🌈 WeatherLab НУШ

**Інтерактивний календар погоди для учнів початкової школи**

## 🎯 Місія
Перетворити кожного учня на маленького науковця, який розуміє природу через щоденні відкриття.

## 🚀 Швидкий старт

1. Відкрийте [https://your-username.github.io/weatherlab-nush](https://your-username.github.io/weatherlab-nush)
2. Пройдіть onboarding wizard
3. Почніть записувати погоду щодня!

## 📱 Встановлення як PWA

- **Android**: Відкрийте в Chrome → "Встановити додаток"
- **iOS**: Відкрийте в Safari → "На екран дому"
- **Desktop**: Натисніть іконку встановлення в адресному рядку

## ♿ Доступність (WCAG 2.2 AA)

- Підтримка екранних читачів
- Навігація з клавіатури
- Високий контраст
- Шрифт для дислексії
- Спрощений режим

## 📊 Функціонал

- Щоденний календар погоди з емодзі
- Порівняння з реальними даними (Open-Meteo API)
- Система досягнень та гейміфікація
- Класні проєкти
- Експорт звітів
- Офлайн-режим (PWA)

## 🛠️ Технології

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **PWA**: Service Worker, Web App Manifest
- **API**: Open-Meteo (метеодані), Nominatim (геокодування)
- **Безпека**: CSP, HTTPS, локальне збереження даних
